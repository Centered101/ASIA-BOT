# นโยบายความเป็นส่วนตัว ASIA-BOT

อัปเดตล่าสุด: 24 สิงหาคม 2569

เอกสารนี้อธิบายว่า ASIA-BOT เก็บ ใช้ และดูแลข้อมูลของผู้ใช้อย่างไร สำหรับนักเรียน ผู้ปกครอง บุคลากร และผู้ดูแลระบบ

หมายเหตุ: ชื่อระบบที่แสดงบนหน้าเว็บสามารถปรับได้จากค่า `NEXT_PUBLIC_SITE_NAME` ใน environment หากโรงเรียนเปลี่ยนชื่อแบรนด์ เอกสารนี้ยังอ้างถึงระบบเดียวกัน

## เราเก็บข้อมูลอะไรบ้าง

- ข้อมูลนักเรียน เช่น รหัสนักเรียน ชื่อ นามสกุล ชื่อเล่น ระดับชั้น สาขา ปีที่เข้าเรียน และรูปโปรไฟล์
- ข้อมูลผู้ปกครองและผู้ติดต่อฉุกเฉิน เช่น ชื่อ ความเกี่ยวข้อง และช่องทางติดต่อ ที่นักเรียนหรือผู้ดูแลบันทึกไว้
- ประวัติการศึกษาเดิม ผลงาน รางวัล การแข่งขัน และประวัติการเปลี่ยนสถานภาพของนักเรียน
- ข้อมูลการเข้าเรียนและการเช็กชื่อ ทั้งรายวันและรายคาบ รวมถึงบันทึกการสแกนบัตรซึ่งมีวันเวลาและสถานที่ที่สแกน
- ข้อมูลบัตรนักเรียนที่ลงทะเบียนไว้กับเครื่องอ่านบัตร
- เอกสารของนักเรียนที่โรงเรียนเก็บไว้ในระบบ และคำขอเอกสารพร้อมประวัติการดำเนินการ
- เรื่องแจ้งซ่อมและครุภัณฑ์ รวมถึงรูปภาพที่ผู้แจ้งแนบมา
- ข้อมูลการใช้งานระบบ เช่น การจองห้อง คำขอเบิกคุรุภัณฑ์ คำสั่งซื้อสหกรณ์ การประเมินโปรเจกต์ และความคิดเห็นที่ส่งเข้ามา
- ข้อมูลใบสมัครครูหรือข้อมูลบุคลากร เมื่อผู้ใช้ส่งแบบฟอร์มสมัครหรือผู้ดูแลบันทึกข้อมูลครูผู้สอน
- ข้อมูลบัญชีที่ใช้เข้าสู่ระบบ เช่น เบอร์โทรสำหรับยืนยันตัวตน หรืออีเมล Google เมื่อผู้ใช้เลือกเชื่อมบัญชี
- ข้อมูลสำหรับแจ้งเตือน เช่น LINE user id การตั้งค่ารับแจ้งเตือน และรายการแจ้งเตือนที่ส่งถึงผู้ใช้
- บันทึกการเข้าสู่ระบบ และบันทึกการทำงานสำคัญของผู้ดูแล เพื่อตรวจสอบย้อนหลัง
- **ข้อความที่ผู้ใช้ส่งให้ ASIA-BOT AI ทั้งทางเว็บและทาง LINE จะถูกบันทึกเก็บไว้** เพื่อให้ระบบตอบคำถาม ทำงานตามคำขอ และให้ผู้ดูแลที่มีสิทธิ์ตรวจสอบคุณภาพและความปลอดภัยของคำตอบย้อนหลังได้

## เราใช้ข้อมูลเพื่ออะไร

- ยืนยันตัวตนและแสดงบัตรประจำตัวนักเรียน
- ดูแลและตรวจสอบการใช้งานบริการของโรงเรียน
- จัดการการจองห้อง คำขอเบิกคุรุภัณฑ์ คำสั่งซื้อสินค้า การประเมินโปรเจกต์ และการติดต่อกลับจากผู้ดูแล
- บันทึกการเข้าเรียนรายคาบ และแจ้งงานที่ครูสั่งให้นักเรียนทราบ
- ดำเนินการเรื่องแจ้งซ่อม ติดตามสถานะ และดูแลทะเบียนครุภัณฑ์ของโรงเรียน
- ออกเอกสารและดำเนินการตามคำขอเอกสารของนักเรียน
- ติดต่อผู้ปกครองในกรณีจำเป็นหรือกรณีฉุกเฉิน
- ตรวจสอบใบสมัครครู จัดการข้อมูลครูผู้สอน และดูแลตารางเรียน
- ปรับปรุงความปลอดภัยของระบบ และตรวจสอบการใช้งานที่ผิดปกติ
- ส่งการแจ้งเตือนที่เกี่ยวข้องกับบัญชีหรือกิจกรรมของผู้ใช้ ทั้งในเว็บและทาง LINE
- ช่วยให้ ASIA-BOT AI ตอบคำถามตามข้อมูลที่ผู้ใช้มีสิทธิ์เข้าถึงเท่านั้น

## ใครเข้าถึงข้อมูลได้

- นักเรียนดูข้อมูลของตนเองได้จากหน้าโปรไฟล์ บัตรนักเรียน ข้อมูลส่วนตัว การเข้าเรียน และเอกสารของฉัน
- ผู้ดูแลระบบเข้าถึงได้เท่าที่สิทธิ์ของบทบาทตนเองกำหนด ระบบแบ่งสิทธิ์ตามฝ่ายและหน้าที่ ไม่ใช่ทุกคนเห็นทุกอย่าง
- **การแจ้งเตือนบางประเภทถูกส่งเข้ากลุ่ม LINE ของโรงเรียน** เช่น การจอง คำสั่งซื้อ ความคิดเห็น และงานแจ้งซ่อม ทุกคนที่อยู่ในกลุ่มนั้นจะเห็นข้อมูลในข้อความแจ้งเตือน
- ข้อมูลบางส่วนอาจถูกส่งไปยังบริการภายนอกที่จำเป็นต่อการให้บริการ ได้แก่ Supabase (ฐานข้อมูลและไฟล์), Vercel (โฮสต์เว็บ), Google OAuth (เข้าสู่ระบบ), LINE Messaging API (แจ้งเตือนและแชท), Stripe (ชำระเงิน) และ Anthropic (ผู้ให้บริการ AI)
- ASIA-BOT ไม่ขายข้อมูลส่วนบุคคลของผู้ใช้

## การเก็บรักษาและความปลอดภัย

- ระบบใช้การเข้าสู่ระบบด้วยคุกกี้ที่มีลายเซ็นกำกับ และแบ่งสิทธิ์การเข้าถึงตามบทบาทของผู้ใช้
- การทำงานสำคัญของผู้ดูแล เช่น การแก้ไข อนุมัติ หรือลบข้อมูล จะถูกบันทึกไว้เพื่อตรวจสอบย้อนหลัง
- ข้อความที่ LINE ส่งเข้าระบบถูกตรวจลายเซ็นก่อนทุกครั้ง เพื่อกันการปลอมแปลงคำขอ
- รูปโปรไฟล์จะถูกครอปเป็นอัตราส่วน 1:1 ก่อนนำไปใช้แสดงผลในระบบ
- ผู้ใช้ควรรักษารหัสผ่าน เบอร์โทร และบัญชี Google ของตนเองให้ปลอดภัย
- หากพบข้อมูลผิดพลาดหรือสงสัยว่าบัญชีถูกใช้งานโดยไม่ได้รับอนุญาต ควรแจ้งผู้ดูแลทันที

## การแจ้งเตือนทาง LINE

- การรับแจ้งเตือนส่วนตัวทาง LINE ต้องผูกบัญชีก่อน โดยแอดเพื่อน LINE ของโรงเรียนแล้วส่ง **รหัสนักเรียน** เข้าไปในแชท
- ระบบยืนยันการผูกบัญชีด้วยรหัสนักเรียนเท่านั้น **ผู้ใช้จึงควรระวังไม่ให้ผู้อื่นทราบรหัสนักเรียนของตน** และหากพบว่าได้รับแจ้งเตือนของคนอื่น หรือไม่ได้รับแจ้งเตือนที่ควรได้รับ ให้แจ้งผู้ดูแลทันที
- ผู้ใช้ยกเลิกการเชื่อมบัญชี LINE ได้ด้วยตนเองจากหน้าโปรไฟล์นักเรียน เมื่อยกเลิกแล้วระบบจะหยุดส่งแจ้งเตือนส่วนตัวไปยังบัญชี LINE นั้น
- เมื่อเปลี่ยนบัญชี LINE หรือเปลี่ยนเครื่อง ควรยกเลิกการเชื่อมของเดิมก่อน เพื่อไม่ให้แจ้งเตือนยังวิ่งไปที่บัญชีเก่า

## สิทธิ์ของผู้ใช้

- ขอดูข้อมูลของตนเองได้จากหน้าโปรไฟล์ บัตรนักเรียน การเข้าเรียนรายคาบ และเอกสารของฉัน
- แก้ไขข้อมูลส่วนตัวของตนเองได้จากหน้าข้อมูลส่วนตัว เช่น ข้อมูลติดต่อ ผู้ปกครอง ประวัติการศึกษาเดิม และผลงาน
- ส่งคำขอแก้ไขข้อมูลสำคัญผ่านระบบได้ โดยข้อมูลที่กระทบทะเบียน เช่น ชื่อ-นามสกุล ต้องรอผู้ดูแลอนุมัติ
- ยกเลิกการเชื่อมบัญชี LINE ได้ด้วยตนเอง ส่วนการยกเลิกเชื่อมบัญชี Google ให้ติดต่อผู้ดูแลระบบ
- ขอให้ผู้ดูแลตรวจสอบ ลบ หรือปิดการใช้งานข้อมูลบางส่วนได้ตามความเหมาะสมของระบบโรงเรียน

## ติดต่อผู้ดูแล

หากต้องการแก้ไข ลบ หรือตรวจสอบข้อมูลส่วนตัว กรุณาติดต่อผู้ดูแลระบบของ ASIA-BOT ผ่านช่องทางของโรงเรียนหรือหน้าแสดงความคิดเห็น
