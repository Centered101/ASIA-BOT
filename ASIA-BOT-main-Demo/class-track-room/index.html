ระบบ Class Track Room

ระบบเช็กสถานะห้องเรียนแบบเรียลไทม์

ระบบนี้ถูกสร้างขึ้นเพื่อช่วยให้ครู นักศึกษา และเจ้าหน้าที่ สามารถตรวจสอบ สถานะการใช้งานของห้องเรียนแบบเรียลไทม์ ว่าห้องไหนกำลังใช้งาน ว่าง อยู่ระหว่างการเรียน หรือถูกจองไว้สำหรับกิจกรรมต่าง ๆ โดยข้อมูลทั้งหมดจะอัปเดตอัตโนมัติผ่านระบบหลังบ้าน เพื่อความแม่นยำและสะดวกในการจัดการห้องเรียนในทุกช่วงเวลา.

วัตถุประสงค์

เพื่อให้ผู้ใช้สามารถตรวจสอบห้องเรียนที่กำลังใช้งานหรือว่างได้ทันที ลดปัญหาการจองซ้ำซ้อน และช่วยให้การวางแผนใช้ห้องเรียนเป็นไปอย่างมีประสิทธิภาพมากขึ้น.

ฟีเจอร์หลัก

แสดงสถานะห้องแบบเรียลไทม์, อัปเดตอัตโนมัติ, รองรับหลายอาคาร, ดูประวัติการใช้งาน, ระบบแจ้งเตือนการเปลี่ยนแปลงสถานะ, และรองรับการขยายสู่การใช้งานโรงเรียนอื่นในอนาคต.

    ห้องเรียน

    กำลังโหลดข้อมูลห้องเรียน...

    เกี่ยวกับระบบเช็กสถานะห้องเรียนแบบเรียลไทม์

    ระบบเช็กสถานะห้องเรียนแบบเรียลไทม์ถูกพัฒนาเพื่อช่วยให้ครูและนักศึกษาตรวจสอบ สถานะการใช้งานของห้องเรียน ได้ทันทีทั้งห้องว่าง ห้องกำลังเรียน หรือห้องถูกจองไว้ โดยข้อมูลจะอัปเดตแบบ Real-Time ผ่าน Dashboard กลาง.

    ระบบนี้ถูกสร้างด้วย HTML, CSS, Tailwind CSS, JavaScript และ jQuery เพื่อให้ใช้งานง่าย ลื่น และรองรับทุกอุปกรณ์ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์.

    สถานะห้องทั้งหมดดึงข้อมูลจาก Google Sheets ที่ทำหน้าที่เป็นฐานข้อมูลกลาง ระบบจะอ่านข้อมูลสถานะห้อง เช่น "ใช้งานอยู่" "ว่าง" หรือ "ไม่พร้อมใช้งาน" และนำมาแสดงผลบนหน้าเว็บแบบอัตโนมัติทันทีที่มีการอัปเดต.

    ระบบสามารถนำไปประยุกต์ใช้กับโรงเรียนหรือสถาบันอื่นได้ โดยผู้พัฒนาจะดูแลระบบต้นฉบับและจัดการการตั้งค่าหลักให้ทั้งหมด เพื่อให้การใช้งานมีความถูกต้องและเสถียรเหมือนเวอร์ชันหลักที่ใช้ในวิทยาลัยเทคโนโลยีเอเชียลพบุรี.
