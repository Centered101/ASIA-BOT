### 1. การเข้าสู่ระบบ

เปิดเบราว์เซอร์แล้วไปที่หน้า **`/login`**

#### วิธีที่ 1 — รหัสนักเรียน + เบอร์โทร

1. กรอก **รหัสนักเรียน** ในช่องแรก
2. กรอก **เบอร์โทรศัพท์** ของตัวเอง (ใช้เป็นรหัสผ่าน)
3. กดปุ่ม **"เข้าสู่ระบบ"**

#### วิธีที่ 2 — Google Account

1. กดปุ่ม **"เข้าสู่ระบบด้วย Google"**
2. เลือกบัญชี Google ที่ผูกกับรหัสนักเรียนไว้แล้ว
3. ระบบจะพาเข้าสู่หน้าโปรไฟล์โดยอัตโนมัติ

> **หมายเหตุ:** Session มีอายุหลายวัน ระบบจะแสดงเวลาคงเหลือที่แถบด้านบนของหน้า

---

### 2. หน้าโปรไฟล์นักเรียน (`/student`)

#### 2.1 บัตรประจำตัวดิจิทัล

บัตรแสดงข้อมูลดังนี้:

| ด้านหน้า | ด้านหลัง |
|----------|----------|
| ชื่อ-นามสกุล | ข้อมูลส่วนตัวครบถ้วน |
| รหัสนักเรียน | สถานะบัตร |
| ระดับชั้น + สาขาวิชา | สถานะการศึกษา |
| QR Code | UID / รหัสบัตร RFID |

- **แตะ/คลิกที่บัตร** เพื่อพลิกดูด้านหลัง
- สีบัตร **น้ำเงิน** = นักเรียน ปวช
- สีบัตร **แดง** = นักเรียน ปวส

#### 2.2 การแก้ไขข้อมูล

กดปุ่ม **"แก้ไขข้อมูล"** — มี 2 ส่วน:

| ส่วน | ข้อมูลที่แก้ได้ | มีผลทันที? |
|------|----------------|-----------|
| **บันทึกทันที** | รูปโปรไฟล์ · ชื่อเล่น · เบอร์โทร | ✅ ทันที |
| **ต้องอนุมัติ** | รหัสนักเรียน · ชื่อ-นามสกุล · ระดับชั้น · ปีที่เข้าเรียน · สาขาวิชา | ⏳ รอ Admin อนุมัติ |

#### 2.3 การอัพโหลดรูปโปรไฟล์

1. กดไอคอน **กล้อง** ที่มุมขวาล่างของรูปโปรไฟล์
2. เลือกไฟล์รูปภาพ (**ไม่เกิน 3MB**)
3. ปรับตำแหน่งภาพในกรอบวงกลม — ลากเพื่อขยับ, เลื่อน Slider เพื่อซูม
4. กดปุ่ม **"บันทึกเป็นรูปโปรไฟล์"**

#### 2.4 การเชื่อมบัญชี Google

1. กดปุ่ม **"เชื่อม Google"** ในหน้าโปรไฟล์
2. เลือกบัญชี Google ที่ต้องการผูก
3. ระบบจะผูกบัญชีกับรหัสนักเรียนโดยอัตโนมัติ

> หลังเชื่อมแล้วสามารถล็อกอินด้วย Google ได้ทันที โดยไม่ต้องกรอกรหัสนักเรียน+เบอร์โทรอีก

### 3. บริการสำหรับนักเรียน

เข้าถึงได้จากกริดเมนูในหน้าโปรไฟล์ (`/student`)

---

#### 3.1 ประเมินโปรเจค (`/projects`)

- ดูผลงานโปรเจคของนักเรียนทุกคน
- กดที่โปรเจคเพื่อเข้าดูรายละเอียด
- ให้คะแนนประเมินผลงาน

---

#### 3.2 จองห้อง (`/class-track-room?view=booking`)

1. เลือก **ห้องที่ต้องการจอง**
2. เลือก **วันที่** และ **ช่วงเวลา** (Time Slot)
3. กรอก **วัตถุประสงค์** และ **จำนวนผู้เข้าร่วม**
4. กดปุ่ม **"ยืนยันการจอง"**
5. รอ Admin อนุมัติ — ระบบจะแจ้งสถานะให้ทราบ

**สถานะการจอง:**

| สถานะ | ความหมาย |
|-------|----------|
| รอดำเนินการ | Admin ยังไม่ได้ตรวจสอบ |
| อนุมัติ | จองสำเร็จ สามารถใช้ห้องได้ |
| ปฏิเสธ | Admin ไม่อนุมัติ |
| ยกเลิก | การจองถูกยกเลิก |

---

#### 3.3 สแกนเข้า/ออก (`/student-entry-scanner`)

> **⏸ ปิดใช้งานชั่วคราว:** ซ่อนลิงก์เมนูนี้ออกจากหน้าแรกและหน้าโปรไฟล์นักเรียนแล้ว (หน้ายังเข้าถึงได้ตรงผ่าน URL แต่ไม่แสดงในเมนู)

- แสดง QR Code ของตัวเองให้เครื่องสแกน
- ใช้สำหรับบันทึกการเข้า-ออก โรงเรียน / ห้องสมุด / ห้องประชุม
- ระบบบันทึกเวลาโดยอัตโนมัติ

---

#### 3.4 Class Track Room (`/class-track-room`)

- ดูตารางเรียนและห้องเรียนของตัวเอง
- ตรวจสอบสถานะห้องแบบ real-time ว่าห้องไหนมีคลาสอยู่

---

#### 3.5 สหกรณ์โรงเรียน (`/shop`)

1. เลือกสินค้าที่ต้องการ
2. เพิ่มลงตะกร้า
3. เลือกวิธีรับสินค้า: **รับที่ร้าน** หรือ **จัดส่ง**
4. ยืนยันคำสั่งซื้อ
5. ติดตามสถานะออร์เดอร์ได้ในหน้าเดิม

---

#### 3.6 ความคิดเห็น/ข้อเสนอแนะ (`/feedback`)

มี 2 ประเภท:

**ความคิดเห็น (Comment)**
- หมวดหมู่: ข้อเสนอแนะ / คำชม / คำถาม / อื่นๆ

**รายงานปัญหา (Report)**
- หมวดหมู่: บั๊ก/ข้อผิดพลาด / ระบบล่ม / ข้อมูลผิดพลาด / ปัญหาการแสดงผล / อื่นๆ

**ตัวเลือกเพิ่มเติม:**
- ส่งแบบ **ไม่ระบุชื่อ** หรือ **ระบุชื่อ**
- แนบรูปภาพได้สูงสุด **3 รูป** (ไม่เกิน 5MB ต่อรูป)

---

#### 3.7 ผู้ช่วย AI — ASIA-BOT AI

ปุ่มแชทลอย (มุมขวาล่าง) เปิดได้ทุกหน้า — ต้อง **เข้าสู่ระบบก่อน** เพราะบอทตอบโดยอ้างอิงข้อมูลของคุณจริง

**ถามข้อมูลได้** เช่น
- "ฉันเข้าโรงเรียนวันนี้หรือยัง" / "ประวัติเข้าออก 7 วัน"
- "ตารางเรียนวันนี้"
- "คำสั่งซื้อล่าสุดของฉัน"

**สั่งให้ทำงานแทนได้** (บอทจะถามยืนยันก่อน)
- "จองห้องประชุมพรุ่งนี้ช่วงบ่าย" → บอทจองให้ รออนุมัติ
- "สั่งข้าวมันไก่ 1 ที่" → บอทสร้างออเดอร์ รอชำระที่สหกรณ์
- "ยกเลิกการจอง" / "ยกเลิกออเดอร์ ORD-xxxx"

> ใช้ผ่าน **LINE** ได้ด้วย — เพิ่มเพื่อน ASIA-BOT แล้วส่ง **รหัสนักเรียน** เพื่อผูกบัญชี จากนั้นพิมพ์คุยได้เลย และอัปโหลดไฟล์ PDF เพื่อถาม-ตอบเนื้อหาในเอกสารได้

## ส่วนที่ 2 — คู่มือผู้ดูแลระบบ (Admin)

---

### สิทธิ์การเข้าถึง

ระบบแบ่งสิทธิ์ผู้ดูแลเป็น 3 ระดับ:

| สิทธิ์ | ป้ายกำกับ | ความสามารถ |
|--------|----------|-----------|
| **Superadmin** | ผู้ดูแลสูงสุด | เข้าถึงได้ทุกเมนู รวมถึงจัดการ Admin อื่น |
| **Admin** | ผู้ดูแลระบบ | เข้าถึงได้เกือบทุกเมนู |
| **Staff** | เจ้าหน้าที่ | เข้าถึงได้เฉพาะเมนูพื้นฐาน |

> เมนูที่แสดงจะแตกต่างกันตามสิทธิ์ หากไม่เห็นเมนูใด แปลว่าบัญชีไม่มีสิทธิ์เข้าถึง กรุณาติดต่อ Superadmin

---

### 1. Dashboard

**เส้นทาง:** `/admin` → เมนู **"ภาพรวมระบบ"**

แสดงสรุปภาพรวมแบบ real-time:

| การ์ด | ข้อมูลที่แสดง |
|-------|-------------|
| นักเรียน | จำนวนนักเรียนทั้งหมด |
| เช็กชื่อวันนี้ | จำนวนนักเรียนที่เข้าวันนี้ |
| การจอง | รายการจองที่รอดำเนินการ |
| บัตร | บัตรไม่ได้ใช้งาน / บัตรหาย |
| คำสั่งซื้อ | ออร์เดอร์ที่ค้างอยู่ |
| Feedback | ความคิดเห็นที่ยังไม่ได้ดำเนินการ |

กราฟแสดง: สถิติการเข้าเรียน · แนวโน้มการจอง · ยอดขายสหกรณ์

### 2. จัดการนักเรียน

#### 2.1 นักเรียน (Students)

**เส้นทาง:** เมนู **"นักเรียน"**

- ดูรายชื่อนักเรียนทั้งหมด รองรับ 3 มุมมอง: **Grid / List / Card**
- ค้นหาด้วย: ชื่อ · รหัสนักเรียน · สาขาวิชา · ระดับชั้น
- กดที่นักเรียนเพื่อดูรายละเอียดและแก้ไขข้อมูล
- จัดการสถานะบัตร:

| สถานะ | ความหมาย |
|-------|----------|
| `active` | บัตรใช้งานได้ปกติ |
| `inactive` | บัตรไม่ได้ใช้งาน |
| `lost` | บัตรหาย |

- ผูก/เปลี่ยน UID บัตร RFID ของนักเรียน

#### 2.2 คำขอแก้ไขข้อมูล (Data Requests)

**เส้นทาง:** เมนู **"คำขอข้อมูลนักเรียน"**

เมื่อนักเรียนส่งคำขอแก้ไขข้อมูล (ชื่อ / รหัส / ระดับ / สาขา ฯลฯ) จะปรากฏที่นี่

**ขั้นตอน:**
1. คลิกที่คำขอเพื่อดูรายละเอียดการเปลี่ยนแปลง
2. เปรียบเทียบข้อมูลเดิม vs ข้อมูลที่ขอแก้ไข
3. กด **"อนุมัติ"** หรือ **"ปฏิเสธ"** พร้อมเพิ่มหมายเหตุ (ถ้ามี)

---

### 3. เช็กชื่อและอุปกรณ์

> **⏸ ปิดใช้งานชั่วคราว:** ซ่อนเมนู "เช็กชื่อและอุปกรณ์" ทั้งหมดออกจากแถบเมนูฝั่งซ้ายของ Admin แล้ว (รวมถึงการ์ดลัดในหน้า Dashboard) — เส้นทาง/ข้อมูลเบื้องหลังยังอยู่ครบ พร้อมเปิดกลับมาใช้ภายหลัง

#### 3.1 เช็กชื่อทั้งหมด (Entry Logs)

**เส้นทาง:** เมนู **"เช็กชื่อ ทั้งหมด"**

- ดูรายการเข้า-ออกทุกสถานที่แบบ real-time
- ตัวเลขบน badge = จำนวนนักเรียนที่เช็กชื่อวันนี้
- กรองตามสถานที่: โรงเรียน / ห้องสมุด / ห้องประชุม

#### 3.2 เช็กชื่อแยกสถานที่

| เมนู | สถานที่ |
|------|--------|
| เช็กชื่อ โรงเรียน | การเข้า-ออกโรงเรียน |
| เช็กชื่อ ห้องสมุด | การเข้า-ออกห้องสมุด |
| เช็กชื่อ ห้องประชุม | การเข้า-ออกห้องประชุม |

แต่ละรายการแสดง: เวลา check-in · เวลา check-out · ระยะเวลาที่อยู่

#### 3.3 เครื่องอ่านบัตร RFID

**เส้นทาง:** เมนู **"เครื่องอ่านบัตร"**

- ตรวจสอบสถานะการเชื่อมต่อของเครื่อง RFID แบบ real-time
- ดู log การสแกนล่าสุด
- **ผูกบัตร:** สแกนบัตร RFID แล้วพิมพ์รหัสนักเรียนเพื่อผูก
- **รีเซ็ตบัตร:** ยกเลิกการผูกบัตรกับนักเรียน

---

### 4. จัดการการจองห้อง

#### 4.1 รายการจองห้อง (Bookings)

**เส้นทาง:** เมนู **"รายการจองห้อง"**

**ตัวเลขบน badge** = จำนวนการจองที่รอดำเนินการ

**ขั้นตอนอนุมัติ/ปฏิเสธ:**
1. คลิกที่รายการจอง
2. ตรวจสอบรายละเอียด: ผู้จอง · ห้อง · เวลา · วัตถุประสงค์ · ผู้เข้าร่วม
3. กด **"อนุมัติ"** หรือ **"ปฏิเสธ"**
4. เพิ่มหมายเหตุ (ถ้ามี) แล้วยืนยัน

**กรองรายการ:** รอดำเนินการ / อนุมัติ / ปฏิเสธ / ยกเลิก

#### 4.2 จัดการห้อง (Rooms)

**เส้นทาง:** เมนู **"จัดการห้อง"**

- **เพิ่มห้องใหม่:** กด "+" แล้วกรอกชื่อ, ที่ตั้ง, ความจุ, สิ่งอำนวยความสะดวก
- **แก้ไขห้อง:** คลิกที่ห้อง แล้วแก้ไขข้อมูล
- **อัพโหลดรูปห้อง:** รองรับในหน้าแก้ไขห้อง
- **สิ่งอำนวยความสะดวก (Amenities):** เลือกเพิ่มจากรายการที่มีในระบบ

---

### 5. สหกรณ์โรงเรียน

#### 5.1 สินค้า (Products)

**เส้นทาง:** เมนู **"สินค้า"**

**ตัวเลขบน badge** = สินค้าที่สต็อกต่ำ

| ฟิลด์ | รายละเอียด |
|-------|-----------|
| ชื่อสินค้า | ชื่อที่แสดงในร้าน |
| ราคา | ราคาขาย |
| ต้นทุน | ต้นทุนสินค้า (สำหรับคำนวณกำไร) |
| สต็อก | จำนวนที่มีอยู่ |
| หน่วย | เช่น ชิ้น, กล่อง, กก. |
| หมวดหมู่ | จัดกลุ่มสินค้า |
| รูปภาพ | รูปสินค้า (อัพโหลดได้หลายรูป) |

- สินค้าที่ `active = false` จะไม่แสดงในหน้าร้านของนักเรียน

#### 5.2 คำสั่งซื้อ (Shop Orders)

**เส้นทาง:** เมนู **"คำสั่งซื้อ"**

**ตัวเลขบน badge** = คำสั่งซื้อที่มีการอัพเดต

| สถานะ | ความหมาย | การดำเนินการ |
|-------|----------|------------|
| pending | รอดำเนินการ | อัพเดตเป็น paid เมื่อชำระเงิน |
| paid | ชำระแล้ว | จัดสินค้าและส่งมอบ |
| cancelled | ยกเลิก | ไม่ต้องดำเนินการ |
| refunded | คืนเงินแล้ว | บันทึกการคืนเงิน |

### 6. โปรเจค

#### 6.1 จัดการโปรเจค (Projects)

**เส้นทาง:** เมนู **"จัดการโปรเจค"**

- เพิ่ม/แก้ไข/ลบโปรเจคนักเรียน
- อัพโหลดไฟล์ประกอบและรูปภาพ
- กำหนด slug (URL) ของโปรเจค

#### 6.2 ผลการประเมิน (Evaluations)

**เส้นทาง:** เมนู **"ผลการประเมิน"**

- ดูสรุปคะแนนประเมินทุกโปรเจค
- กราฟเปรียบเทียบคะแนนระหว่างโปรเจค
- ดูรายละเอียดแยกตามผู้ประเมิน

### 7. การเรียนการสอน

#### 7.1 กลุ่มเรียน (Class Groups)

**เส้นทาง:** เมนู **"กลุ่มเรียน"** *(Admin ขึ้นไป)*

- สร้างกลุ่มเรียน (ห้องเรียน)
- กำหนดนักเรียนที่อยู่ในกลุ่ม
- ผูกกลุ่มกับตารางเรียน

#### 7.2 ตารางเรียน (Class Schedule)

**เส้นทาง:** เมนู **"ตารางเรียน"** *(Admin ขึ้นไป)*

**ตารางสัปดาห์**
- กำหนดตารางเรียนปกติ จันทร์–ศุกร์
- ระบุวิชา, ครู, ห้องเรียน, เวลาเริ่ม-สิ้นสุด

**แก้วันพิเศษ**
- เพิ่มวันหยุด
- เปลี่ยนห้องเรียนชั่วคราว
- ยกเลิกคาบเรียนเฉพาะวัน

#### 7.3 ครูผู้สอน (Teachers)

**เส้นทาง:** เมนู **"ครูผู้สอน"** *(Admin ขึ้นไป)*

- เพิ่ม/แก้ไขข้อมูลครูผู้สอน
- ผูกครูกับวิชาและกลุ่มเรียน

### 8. ระบบ

#### 8.1 ความคิดเห็น (Feedbacks)

**เส้นทาง:** เมนู **"ความคิดเห็น"**

**ตัวเลขบน badge** = Feedback ที่ยังไม่ได้ดำเนินการ

**การอัพเดตสถานะ:**

```
รอดำเนินการ → กำลังดำเนินการ → แก้ไขแล้ว
                              ↘ ปฏิเสธ
```

1. คลิกที่ Feedback เพื่อดูรายละเอียด (รวมถึงรูปภาพที่แนบ)
2. เลือกสถานะที่ต้องการ
3. บันทึก

#### 8.2 ส่งข่าวสาร (Line Broadcast)

**เส้นทาง:** เมนู **"ส่งข่าวสาร"**

- พิมพ์ข้อความที่ต้องการส่ง
- กดส่ง → ระบบจะ broadcast ผ่าน LINE Official Account ของโรงเรียน

#### 8.3 ผู้ดูแลระบบ (Admins)

**เส้นทาง:** เมนู **"ผู้ดูแลระบบ"** *(Superadmin / Admin)*

**การเพิ่ม Admin ใหม่:**
1. กด **"เพิ่มผู้ดูแล"**
2. กรอก username, ชื่อ-นามสกุล, รหัสผ่าน
3. เลือกสิทธิ์: `superadmin` / `admin` / `staff`
4. บันทึก

**การแก้ไข/ลบ Admin:**
- คลิกที่ Admin แล้วกด **"แก้ไข"** หรือ **"ลบ"**

#### 8.4 ตั้งค่า (Settings)

**เส้นทาง:** เมนู **"ตั้งค่า"**

- ตั้งค่าระบบทั่วไปของโรงเรียน

#### 8.5 ผู้ช่วย AI สำหรับ Admin

ปุ่มแชทลอยในหน้า Admin ใช้ธีมมืด-แดงเข้ากับ Admin Panel และให้ข้อมูลเชิงบริหาร เช่น
- "สถิตินักเรียนวันนี้" / "รายงานการเข้าออก"
- "การจองห้องที่รอ approve" / "ดู feedback ทั้งหมด"
- ค้นหานักเรียน, สรุปยอดสหกรณ์

> บอทแสดงปุ่มลิงก์ไปยังแท็บที่เกี่ยวข้อง (เช่น `/admin?tab=bookings`) ให้กดได้ทันที และจำกัดสิทธิ์ตาม role ของผู้ดูแล

---

### 9. การเข้าสู่ระบบ Admin

1. ไปที่ URL **`/admin`**
2. กรอก **Username** และ **Password** ของบัญชี Admin
3. กดปุ่ม **"เข้าสู่ระบบ"**

> **Session Admin มีอายุ 8 ชั่วโมง** หลังจากนั้นต้องล็อกอินใหม่
