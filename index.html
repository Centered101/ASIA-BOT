ASIA-LB Overview

ระบบเว็บไซต์โครงงานนักศึกษา

แพลตฟอร์มนี้รวบรวมและแสดงผลโปรเจกต์นักศึกษา วิทยาลัยเทคโนโลยีเอเชียลพบุรี มี 3 ระบบหลัก: ระบบประเมินโครงงาน, ระบบเช็กสถานะห้องเรียนแบบเรียลไทม์, และ ระบบสแกนบัตรเข้าโรงเรียน. เว็บไซต์นี้สามารถนำไปใช้กับโรงเรียนหรือสถาบันอื่นได้ตามความเหมาะสม โดยทีมผู้พัฒนายังคงควบคุมและดูแลระบบต้นฉบับ

วัตถุประสงค์

เพื่อสร้างแพลตฟอร์มที่ช่วยให้การประเมินโครงงานเป็นไปอย่างสะดวก รวดเร็ว และแม่นยำ รวมทั้งช่วยติดตามสถานะห้องเรียนแบบเรียลไทม์ และจัดการการเข้าออกโรงเรียนผ่านระบบสแกนบัตร ทั้งหมดนี้ถูกนำเสนอในรูปแบบดิจิทัลที่เข้าใจง่าย.

เป้าหมาย

เพื่อเพิ่มประสิทธิภาพในการประเมินโครงงาน ลดข้อผิดพลาดในการจัดเก็บข้อมูล และสร้างความสะดวกในการติดตามผลการเรียนและการเข้าออกโรงเรียน ทำให้กระบวนการทั้งหมดโปร่งใสและง่ายต่อการจัดการ.

ลิงก์ด่วน

    เกี่ยวกับเว็บไซต์

    เว็บไซต์ Asia-LB Project System ถูกสร้างขึ้นเพื่อจัดการ 3 ระบบหลักของนักศึกษา ได้แก่ ระบบประเมินโครงงาน, ระบบเช็กสถานะห้องเรียนแบบเรียลไทม์ และ ระบบสแกนบัตรเข้าโรงเรียน. ระบบถูกพัฒนาด้วย HTML, CSS, Tailwind CSS, JavaScript และ jQuery เพื่อให้ใช้งานง่ายและรองรับทุกอุปกรณ์.

    ข้อมูลทั้งหมดเชื่อมต่อกับ Google Sheets เป็นฐานข้อมูลกลาง สำหรับรับและส่งข้อมูล เช่น รายการโครงงาน ผลการประเมิน หรือสถานะต่าง ๆ ของนักศึกษาและคณะกรรมการ จากนั้นนำข้อมูลมาแสดงผลแบบ เรียลไทม์บน Dashboard ช่วยให้ติดตามความคืบหน้าได้สะดวก.

    เว็บไซต์ยังใช้ AOS (Animate On Scroll) สำหรับสร้างแอนิเมชันระหว่างเลื่อนหน้า และ Font Awesome สำหรับไอคอน ทำให้หน้าเว็บทันสมัยและเป็นมิตรต่อผู้ใช้.

    แม้เว็บไซต์จะพัฒนาขึ้นเพื่อใช้กับวิทยาลัยเทคโนโลยีเอเชียลพบุรีเป็นหลัก แต่โรงเรียนหรือสถาบันอื่นก็สามารถนำระบบไปใช้งานได้ตามความเหมาะสม โดยการจัดการ ควบคุม และดูแลระบบต้นฉบับยังอยู่ภายใต้ความรับผิดชอบของทีมผู้พัฒนาเว็บ
